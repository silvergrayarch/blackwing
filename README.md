## Blackwing

Blackwing is designed for users who want to find specific types of Twitch streams. It allows you to search by category and filters to find the perfect streams for you.

## Overview

- Uses the third party site `twitch-tools` to gather initial channel previews and data.
- Supplements other neeeded data with the Twitch API to fetch things like follower counts and specific channel details.
- Has Pythonic logic for tag filtering (e.g., `(english or japanese) and vtuber`).
- Excludes channels containing specific words in the title, tags, or channel panels using the bad kewords section (csv)
- Filters by maximum viewer count and maximum follower count.
